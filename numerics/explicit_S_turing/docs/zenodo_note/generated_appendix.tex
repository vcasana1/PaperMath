\section{Programs}\label{app:code}
The programs are written in Python~3 and use \texttt{python-flint} (Arb ball arithmetic \cite{Johansson2017}, FLINT \cite{FLINT}) at $256$ bits, \texttt{numpy}, \texttt{scipy}, \texttt{cvxpy} with the solver Clarabel, and \texttt{mpmath} (in \texttt{opt\_line.py} only). The certification programs are those of Sections~\ref{app:certutil}--\ref{app:cert_line}; every bound they print or write to a file is converted to decimal with directed rounding (\texttt{up\_str} in \texttt{certutil.py}), so that the printed decimal is itself a valid bound. Each certificate begins with the SHA-256 digests of its input file and of the programs that produced it, and the versions of Python and \texttt{python-flint}; the build script of this note checks that these digests are those of the files reproduced in Appendices~\ref{app:code} and~\ref{app:data}. The search programs that produced the coefficients are reproduced in Section~\ref{app:search} for completeness, but no statement of this article depends on them. All files are in the repository cited in Section~\ref{sec:methods}, in the folders \texttt{hybrid\_asymptotic/} and \texttt{family/}; the deposited archive is flat, and the programs locate their helper modules in either layout.
\appsub{\texttt{certutil.py}: shared helpers, directed decimal rounding of bounds}
\label{app:certutil}
\begin{lstlisting}
# Shared helpers of the certification programs (python-flint / Arb ball arithmetic at 256 bits).
#   A(q)            exact ball of a Fraction or of an integer (floats are refused)
#   box(lo, hi)     ball containing the interval [lo, hi]
#   exact(x)        the rational value of an exact (zero-radius) arb
#   up_str(x, n)    decimal string with n significant digits that is >= every point of the ball x (directed rounding)
#   down_str(x, n)  decimal string with n significant digits that is <= every point of the ball x
#   provenance(...) lines with the SHA-256 of the input and program files and the library versions, for the record
# The .str() method of arb rounds to the nearest decimal, so it must not be used to print an upper or lower bound;
# every bound printed or written to a JSON file by the certification programs goes through up_str / down_str.
import hashlib, os, sys, platform
from fractions import Fraction as Fr
from decimal import Decimal, ROUND_CEILING, ROUND_FLOOR, localcontext
import flint
from flint import arb, ctx
ctx.prec = 256

def A(q):
    # exact ball of a Fraction or an integer; floats are refused, so that no binary approximation of a decimal enters silently
    if isinstance(q, Fr): return arb(q.numerator)/arb(q.denominator)
    assert isinstance(q, int), 'A() takes a Fraction or an integer, got %r' % (q,)
    return arb(q)

def box(lo, hi):
    return A(lo).union(A(hi))

def exact(x):
    assert x.is_exact() and x.is_finite(), x
    m, e = x.man_exp()
    return Fr(int(m))*Fr(2)**int(e)

def _dir_str(q, n, rounding):
    with localcontext() as c:
        c.prec = n; c.rounding = rounding
        dec = Decimal(q.numerator)/Decimal(q.denominator)      # correctly rounded to n significant digits
    return format(dec, 'f')

def up_str(x, n):
    u = exact(x.upper()); s = _dir_str(u, n, ROUND_CEILING)
    assert Fr(s) >= u, (s, u)
    return s

def down_str(x, n):
    l = exact(x.lower()); s = _dir_str(l, n, ROUND_FLOOR)
    assert Fr(s) <= l, (s, l)
    return s

def sha256(path):
    h = hashlib.sha256()
    with open(path, 'rb') as fh: h.update(fh.read())
    return h.hexdigest()

def provenance(*paths):
    # one line per file (name and SHA-256), then the versions of Python and python-flint and the working precision
    lines = ['%s sha256 %s' % (os.path.basename(p), sha256(p)) for p in paths]
    lines.append('python %s, python-flint %s, precision %d bits' % (platform.python_version(), getattr(flint, '__version__', '?'), ctx.prec))
    return '\n'.join(lines)

if __name__ == '__main__':
    x = arb(1)/3
    print(x.str(12, radius=False), up_str(x, 12), down_str(x, 12))
    y = -arb(1)/7
    print(y.str(12, radius=False), up_str(y, 12), down_str(y, 12))
\end{lstlisting}
\appsub{\texttt{certify\_hybrid.py}: certification of the kernel inequality (with or without discs) and of $C_{\rm H}$}
\label{app:cert_hybrid}
\begin{lstlisting}
# Certification (Arb ball arithmetic, python-flint, 256 bits) of the kernel inequality
#   f(b,t) <= U(b,t) + sum_k kappa_k W_k(b,t)     for 0 <= b <= 1/2, t != 0,
# with f(b,t) = 2 atan((d+b)/t) + 2 atan((d-b)/t) - atan((2d+b)/t) - atan((2d-b)/t),
#      U(b,t) = sum_iota c_iota [F_iota(d+b,t) + F_iota(d-b,t)],  F_Rj = Re (x+it)^(-j),  F_Ij = -Im (x+it)^(-j),
#      W_k(b,t) = log^+( R_k / sqrt((c_k-1/2-b)^2 + (t+v_k)^2) ),
# and of the constant C_H = c_R1/(2 pi) + (1/pi) sum_k kappa_k J_k,  J_k = (1/pi) int_0^pi e_P(c_k + R_k cos th) dth,
# where e_P is the piecewise linear profile of profile_published.py.  With an empty list of discs the program certifies
# the kernel inequality f <= U alone and prints C_1 = c_R1/(2 pi).
#
# Usage:  python3 certify_hybrid.py <solution.json> [T1]
#   solution.json: d, B (basis), c (coefficients, exact binary values), discs [(c_k,R_k,v_k)], kappa; T1 defaults to 40.
# Method (Proposition "Certification of the kernel inequality" and Section "The hybrid" of the article):
#   (a) on [0,1/2] x (0,T1] and [0,1/2] x [-T1,0): centred form H(centre) + grad H(box) . half-widths, bisection;
#   (b) for |t| >= T1, u = 1/t: t^2 U - 4 d^3 u - K5 |u|^3 > 0 on [0,1/2] x [0,1/T1] and [0,1/2] x [-1/T1,0], bisection;
#       this needs T1 >= 2d + 1/2 (convergence of the arctan series) and W_k = 0 for |t| >= T1.
import sys, os, json, time
from fractions import Fraction as Fr
from flint import arb, acb
from certutil import A, box, up_str, down_str, exact, provenance

sol = json.load(open(sys.argv[1])); T1 = Fr(sys.argv[2]) if len(sys.argv) > 2 else Fr(40)
d = Fr(sol['d']).limit_denominator(10**6); B = [tuple(x) for x in sol['B']]
c = [Fr(x) for x in sol['c']]                                           # exact binary values written by the optimiser
discs = [(Fr(cc).limit_denominator(10**4), Fr(R).limit_denominator(10**4), Fr(v).limit_denominator(10**4)) for cc, R, v in sol['discs']]
discs = [(cc, min(R, cc-Fr(1, 2)), v) for cc, R, v in discs]            # rational rounding must keep c_k - R_k >= 1/2 (a smaller R_k only lowers W_k)
kap = [Fr(x) for x in sol['kappa']]
# integrity of the data
assert len(c) == len(B) and len(discs) == len(kap)
assert B[0] == ('R', 1) and ('R', 2) in B and all(k in ('R', 'I') and j >= 1 for k, j in B) and ('I', 1) not in B
assert d > Fr(1, 2)
assert all(k >= 0 for k in kap) and all(R > 0 and cc-R >= Fr(1, 2) and cc > 1 for cc, R, v in discs)
assert T1 >= 2*d+Fr(1, 2)
assert all(abs(v)+R <= T1 for cc, R, v in discs)                         # then W_k = 0 for |t| >= T1
JMAX = max(j for _, j in B)
dA = A(d); half = A(Fr(1, 2)); PI = arb.pi()
cA = [A(x) for x in c]; kA = [A(x) for x in kap]; dsA = [(A(cc), A(R).log(), A(v)) for cc, R, v in discs]

def powers(x, t, n):
    # [(x+it)^0, (x+it)^-1, ..., (x+it)^-n]
    w = acb(1)/acb(x, t); pw = [acb(1)]
    for _ in range(n): pw.append(pw[-1]*w)
    return pw
def kernel(b, t):
    U = arb(0)
    for x in (dA+b, dA-b):
        pw = powers(x, t, JMAX)
        for i, (k, j) in enumerate(B):
            U += cA[i]*(pw[j].real if k == 'R' else -pw[j].imag)
    return U
def fbox(b, t, sgn):
    # f on the closure of t > 0 (sgn = +1) or of t < 0 (sgn = -1), in the form regular at t = 0
    return sgn*PI-2*(t/(dA+b)).atan()-2*(t/(dA-b)).atan()+(t/(2*dA+b)).atan()+(t/(2*dA-b)).atan()
def Wlow(b, t):
    # lower bound of sum_k kappa_k W_k on the box (W_k >= 0, so dropping a term is safe)
    s = arb(0)
    for (cc, lR, v), k in zip(dsA, kA):
        val = lR-((cc-half-b)**2+(t+v)**2).log()/2
        lo = val.lower()
        if lo > 0: s += k*lo
    return s
def grad(b, t):
    # partial derivatives of U - f with respect to b and t, on a box
    gb = arb(0); gt = arb(0)
    for x, sg in ((dA+b, 1), (dA-b, -1)):
        pw = powers(x, t, JMAX+1)
        for i, (k, j) in enumerate(B):
            dx = -j*pw[j+1]; dt = acb(0, -j)*pw[j+1]                      # d/dx (x+it)^-j,  d/dt (x+it)^-j
            if k == 'R': gb += cA[i]*sg*dx.real; gt += cA[i]*dt.real
            else: gb -= cA[i]*sg*dx.imag; gt -= cA[i]*dt.imag
    y1 = dA+b; y2 = dA-b; y3 = 2*dA+b; y4 = 2*dA-b; t2 = t*t
    ft = -2*y1/(y1*y1+t2)-2*y2/(y2*y2+t2)+y3/(y3*y3+t2)+y4/(y4*y4+t2)
    fb = 2*t/(y1*y1+t2)-2*t/(y2*y2+t2)-t/(y3*y3+t2)+t/(y4*y4+t2)
    return gb-fb, gt-ft
def Hcentered(b0, b1, t0, t1, sgn):
    bm = (b0+b1)/2; tm = (t0+t1)/2; b = box(b0, b1); t = box(t0, t1)
    H0 = kernel(A(bm), A(tm))-fbox(A(bm), A(tm), sgn)
    gb, gt = grad(b, t)
    H = H0+gb*box(-(b1-b0)/2, (b1-b0)/2)+gt*box(-(t1-t0)/2, (t1-t0)/2)
    return H+Wlow(b, t)
def cert_main(blo, bhi, tlo, thi, sgn, maxdepth=60):
    stack = [(blo, bhi, tlo, thi, 0)]; n = 0
    while stack:
        b0, b1, t0, t1, dep = stack.pop(); n += 1
        H = Hcentered(b0, b1, t0, t1, sgn)
        if H > 0: continue
        if dep >= maxdepth: raise RuntimeError('fail at b=[%s,%s] t=[%s,%s] H=%s' % (float(b0), float(b1), float(t0), float(t1), H))
        wb = (b1-b0)/Fr(1, 20); tm = max(abs(t0), abs(t1)); wt = (t1-t0)/max(Fr(1, 20), tm*Fr(3, 10))
        if wb >= wt: m_ = (b0+b1)/2; stack += [(b0, m_, t0, t1, dep+1), (m_, b1, t0, t1, dep+1)]
        else: m_ = (t0+t1)/2; stack += [(b0, b1, t0, m_, dep+1), (b0, b1, m_, t1, dep+1)]
    return n

# tail |t| >= T1, u = 1/t:  t^2 (U - f) >= t^2 U - 4 d^3 u - K5 |u|^3,  with t^2 U = sum_iota c_iota [Phi_iota(d+b,u) + Phi_iota(d-b,u)],
# Phi_R1 = x/(1+x^2 u^2),  Phi_iota = Re / -Im of u^(j-2) (xu+i)^(-j) for j >= 2;  K5 = (1/5) sum_i |alpha_i| y_i^5 (Lemma "The tail of the kernel").
def tailval(b, u):
    V = arb(0)
    for x in (dA+b, dA-b):
        for i, (k, j) in enumerate(B):
            if j == 1: V += cA[i]*x/(1+x*x*u*u)
            else:
                z = acb(u)**(j-2)*(acb(1)/acb(x*u, 1))**j
                V += cA[i]*(z.real if k == 'R' else -z.imag)
    return V
K5 = (2*(dA+half)**5+2*dA**5+(2*dA+half)**5+(2*dA)**5)/5
def cert_tail(u0, u1, maxdepth=40):
    assert max(abs(u0), abs(u1))*(2*d+Fr(1, 2)) <= 1                   # |y u| <= 1 for every y in {d+b, d-b, 2d+b, 2d-b}
    stack = [(Fr(0), Fr(1, 2), u0, u1, 0)]; n = 0
    while stack:
        b0, b1, a0, a1, dep = stack.pop(); n += 1
        b = box(b0, b1); u = box(a0, a1)
        H = tailval(b, u)-4*dA**3*u-K5*abs(u)**3
        if H > 0: continue
        if dep >= maxdepth: raise RuntimeError('tail fail b=[%s,%s] u=[%s,%s] H=%s' % (float(b0), float(b1), float(a0), float(a1), H))
        if (b1-b0)*8 >= (a1-a0)*T1: m_ = (b0+b1)/2; stack += [(b0, m_, a0, a1, dep+1), (m_, b1, a0, a1, dep+1)]
        else: m_ = (a0+a1)/2; stack += [(b0, b1, a0, m_, dep+1), (b0, b1, m_, a1, dep+1)]
    return n

def Jexact(nodes, cc, R):
    # (1/pi) int_0^pi e(cc + R cos th) dth for e piecewise linear through nodes, e = 0 for sigma >= 1; needs cc - R >= 1/2
    assert nodes[0][0] == Fr(1, 2) and nodes[-1] == (Fr(1), Fr(0)) and all(p[0] < q[0] for p, q in zip(nodes, nodes[1:]))
    tot = arb(0); ccA = A(cc); RA = A(R)
    lo, hi = cc-R, min(cc+R, Fr(1))
    for (p, ep), (q, eq) in zip(nodes, nodes[1:]):
        a, bq = max(p, lo), min(q, hi)
        if a >= bq: continue
        Bs = (eq-ep)/(q-p); As = ep-Bs*p                                 # e = As + Bs sigma on [p, q]
        tha = A((a-cc)/R).acos(); thb = A((bq-cc)/R).acos()               # tha >= thb
        tot += (A(As)+A(Bs)*ccA)*(tha-thb)+A(Bs)*RA*(tha.sin()-thb.sin())
    return tot/PI

if __name__ == '__main__':
    t_ = time.time()
    print(provenance(sys.argv[1], __file__, os.path.join(os.path.dirname(os.path.abspath(__file__)), 'certutil.py'), *([os.path.join(os.path.dirname(os.path.abspath(__file__)), 'profile_published.py')] if sol['discs'] else [])))
    if discs:
        assert sol['prof'] == 'P', 'only the published-source profile e_P is supported'
        from profile_published import nodes_published
        nodes = nodes_published()
        J = [Jexact(nodes, cc, R) for cc, R, v in discs]
    else: J = []
    C = cA[0]/(2*PI)+sum((k*j for k, j in zip(kA, J)), arb(0))/PI
    print('d =', d, ' m =', JMAX, ' discs used:', len(discs), (' profile e_P (profile_published.py)' if discs else ''))
    print('C = c_R1/(2pi) + sum kappa_k J_k/pi =', C.str(25), ' (ball, midpoint and radius)')
    print('   radius of the ball:', C.rad().str(3), '  enclosure of C with directed rounding: [%s, %s]' % (down_str(C, 20), up_str(C, 20)))
    print('kernel part c_R1/(2pi) =', (cA[0]/(2*PI)).str(20))
    lim = 2*dA*cA[0]-2*cA[B.index(('R', 2))]; print('limit of t^2 U at |t| -> oo = 2 d c_R1 - 2 c_R2 =', lim.str(10), ' positive:', lim > 0)
    n1 = cert_main(Fr(0), Fr(1, 2), Fr(0), T1, +1); print('t in (0,T1]: certified, boxes', n1, flush=True)
    n2 = cert_main(Fr(0), Fr(1, 2), -T1, Fr(0), -1); print('t in [-T1,0): certified, boxes', n2, flush=True)
    n3 = cert_tail(Fr(0), 1/T1); n4 = cert_tail(-1/T1, Fr(0)); print('|t|>=T1: certified, boxes', n3+n4)
    Cup = up_str(C, 12); assert exact(C.upper()) <= Fr(Cup)
    print('all certified;  C <', Cup, '  time %.0fs' % (time.time()-t_))
\end{lstlisting}
\appsub{\texttt{profile\_published.py}: the nodes of the profile $\mathfrak e_{\rm P}$}

\begin{lstlisting}
# Upper bound for mu(sigma) on [1/2,1] from published sources only, as a piecewise linear function through nodes
# (sigma_i, e_i) with mu(sigma_i) <= e_i a theorem in each case:
#  - 1/2: 13/84 (Bourgain 2017, Thm 5);
#  - breakpoints of Trudgian-Yang, Toward optimal exponent pairs, arXiv:2306.05599v3, Thm 2.4 (pieces are continuous);
#  - l-k for the exponent pairs (k,l) of Tao-Trudgian-Yang, arXiv:2501.16779v1, Thm 20, via Lemma 23 (mu(l-k) <= k);
#  - Heath-Brown 2017 (Proc. Steklov Inst. Math. 296), Thm 2: pairs (2/((n-1)^2(n+2)), 1-(3n-2)/(n(n-1)(n+2))+eps), n >= 3,
#    giving mu(sigma_n) <= mu_n, sigma_n = 1-(3n^2-3n+2)/(n(n-1)^2(n+2)), mu_n = 2/((n-1)^2(n+2)) (continuity of mu), 6 <= n <= 399;
#  - (1, 0) (zeta(1+it) << log t).
# The profile is the lower convex hull of these points (nodes above a chord of two others are dropped: the chord is a
# valid bound by the Phragmen-Lindelof interpolation lemma, and smaller).
from fractions import Fraction as Fr
TY = [(Fr(1,2),Fr(88225,153852),Fr(31,84),Fr(3,7)),(Fr(88225,153852),Fr(521,796),Fr(220633,620612),Fr(62831,155153)),
 (Fr(521,796),Fr(53141,76066),Fr(1333,3825),Fr(1508,3825)),(Fr(53141,76066),Fr(3620,5119),Fr(405,1202),Fr(227,601)),
 (Fr(3620,5119),Fr(52209,69128),Fr(49318855,170145110),Fr(52938216,170145110)),(Fr(52209,69128),Fr(1389,1736),Fr(471957,1682490),Fr(502648,1682490)),
 (Fr(1389,1736),Fr(134765,163248),Fr(2841,10316),Fr(3016,10316)),(Fr(134765,163248),Fr(18193,21906),Fr(859,3214),Fr(908,3214)),
 (Fr(18193,21906),Fr(249,280),Fr(5*8707,180277),Fr(5*9067,180277)),(Fr(249,280),Fr(277,300),Fr(29,130),Fr(30,130))]
PAIRS = [(Fr(89,1282),Fr(997,1282)),(Fr(652397,9713986),Fr(7599781,9713986)),(Fr(10769,351096),Fr(609317,702192)),(Fr(89,3478),Fr(15327,17390))]
def hb(n): return 1-Fr(3*n*n-3*n+2, n*(n-1)**2*(n+2)), Fr(2, (n-1)**2*(n+2))
def raw_nodes(nmax=400):
    for (l1,h1,a1,b1),(l2,h2,a2,b2) in zip(TY,TY[1:]): assert a1-b1*h1 == a2-b2*h1
    nodes = {}
    for lo,hi,a,b in TY: nodes[lo] = a-b*lo; nodes[hi] = a-b*hi
    for k,l in PAIRS: nodes[l-k] = min(nodes.get(l-k, Fr(1)), k)
    for n in range(6, nmax): s,m = hb(n); nodes[s] = min(nodes.get(s, Fr(1)), m)
    nodes[Fr(1)] = Fr(0)
    return sorted(nodes.items())
def nodes_published(nmax=400):
    P = raw_nodes(nmax); hull = []
    def cross(o,a,b): return (a[0]-o[0])*(b[1]-o[1])-(a[1]-o[1])*(b[0]-o[0])
    for p in P:
        while len(hull) >= 2 and cross(hull[-2], hull[-1], p) <= 0: hull.pop()
        hull.append(p)
    return hull
if __name__ == '__main__':
    H = nodes_published()
    print(len(H), 'nodes; first ones:')
    for s,e in H[:14]: print('  sigma = %-20s  e = %-18s  (%.6f, %.6f)' % (s, e, s, e))
\end{lstlisting}
\appsub{\texttt{cz\_gen\_pp.py}: certification of $C_\zeta$ (per-prime phase maximum)}
\label{app:cert_cz}
\begin{lstlisting}
# Rigorous upper bound (Arb ball arithmetic, 256 bits) for the Euler-product constant of a kernel,
#   C_zeta = sum_{p <= P0} M_p + sum_{n = p^k, p > P0} Lambda(n) n^(-sigma1) h(log n) + tail,
# with h(L) = sqrt(a(L)^2 + b(L)^2),  a(L) = -(1/pi) sum_{(R,j)} c_{R,j} L^(j-1)/(j-1)!,
# b(L) = (1/pi) [ (e^(-dL) - 2)/L - sum_{(I,j)} c_{I,j} L^(j-1)/(j-1)! ],  and M_p the maximum over the phase x of
#   f_p(x) = sum_{k: p^k <= N0} (log p) p^(-k sigma1) [ a(k log p) cos(kx) + b(k log p) sin(kx) ]
# (per-prime phase maximum, Lemma "The contribution of one prime"), bounded by the maximum on a grid of M points plus a
# Lipschitz correction.  The sum over the prime powers n <= N0 is exact; the tail n > N0 uses Lemma "The tail" with the
# non-increasing step majorant G of g(x) = h(log x) x^(-sigma1) on [N0, e^LB], the certified monotonicity of g beyond e^LB
# (Lemma "Monotonicity of g") and psi(x) < 1.03883 x (Rosser-Schoenfeld 1962, Thm 12).
#
# Usage:  python3 cz_gen_pp.py <solution.json> <N0> [P0]      (the article uses N0 = 1e8, P0 = 1000)
# Output: <solution>_czpp.json with the upper bound 'Czeta_upper' (decimal rounded upwards).
import sys, os, json, time, numpy as np
from fractions import Fraction as Fr
from math import factorial
from flint import arb, acb
sys.path.append(os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'hybrid_asymptotic'))   # certutil.py lives there (or next to this file in the flat archive)
from certutil import A, up_str, provenance

sol = json.load(open(sys.argv[1])); N0 = int(float(sys.argv[2])); P0 = int(sys.argv[3]) if len(sys.argv) > 3 else 1000
print(provenance(sys.argv[1], __file__, os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'hybrid_asymptotic', 'certutil.py') if not os.path.exists(os.path.join(os.path.dirname(os.path.abspath(__file__)), 'certutil.py')) else os.path.join(os.path.dirname(os.path.abspath(__file__)), 'certutil.py')), flush=True)
d = Fr(sol['d']).limit_denominator(10**6); B = [tuple(b) for b in sol['B']]; c = [A(Fr(x)) for x in sol['c']]
assert len(c) == len(B) and B[0] == ('R', 1) and ('I', 1) not in B and d > Fr(1, 2) and P0 <= N0
PI = arb.pi(); dA = A(d); s1 = A(Fr(1, 2)+d); alpha = s1-1                 # alpha = sigma1 - 1 > 0
# polynomial coefficients (in L) of pi*a and of the polynomial part of pi*b
DEG = max(j for _, j in B)-1
pa = [arb(0)]*(DEG+1); pb = [arb(0)]*(DEG+1)
for (k, j), cc in zip(B, c):
    if k == 'R': pa[j-1] -= cc/factorial(j-1)
    else: pb[j-1] -= cc/factorial(j-1)
def poly(p, L): return sum((p[i]*L**i for i in range(len(p))), arb(0))
def h(L):

    # symmetric grid of heights t: geometric on [1e-4, tmax] plus a linear part on (0, 4], and a point near 0
    p = np.unique(np.concatenate([[1e-9], np.geomspace(1e-4, tmax, ngeom), np.linspace(0, 4, nlin)[1:]])); return np.concatenate([-p[::-1], p])

def bourgain_nodes():
    # piecewise linear profile through (lambda_j - kappa_j, kappa_j), (kappa_j, lambda_j) = A^j (13/84, 55/84), j = 0..7, and (1, 0)
    k, l = Fr(13, 84), Fr(55, 84); nodes = []
    for _ in range(8):
        nodes.append((l-k, k)); k, l = k/(2*k+2), Fr(1, 2)+l/(2*k+2)
    nodes.append((Fr(1), Fr(0))); return nodes

def J_float(nodes, c, R, n=40001):
    # (1/pi) int_0^pi e(c + R cos th) dth, e piecewise linear through nodes on [1/2, 1], e = 0 for sigma >= 1 (trapezoidal rule)
    xs = np.array([float(a) for a, _ in nodes]); es = np.array([float(e) for _, e in nodes])
    th = np.linspace(0, np.pi, n); s = c+R*np.cos(th); v = np.where(s >= 1, 0, np.interp(s, xs, es))
    return np.trapezoid(v, th)/np.pi

# Search program (not a certificate): the hybrid of the kernel majorant with Jensen discs.
# Linear programme in (c_iota, kappa_k):
#   minimise  c_R1/(2 pi) + (1/pi) sum_k kappa_k J_k
#   subject to  f(b,t) + eta/(1+t^2) <= U(b,t) + sum_k kappa_k W_k(b,t)  on a grid of (b,t), refined by cutting planes,
#               2 d c_R1 - 2 c_R2 >= eta  (limit of t^2 U at |t| -> oo),  kappa_k >= 0,
# with J_k = (1/pi) int_0^pi e(c_k + R_k cos th) dth for the profile e (PROF=P: e_P of profile_published.py; PROF=B: the
# Bourgain profile of lpcommon.bourgain_nodes).  Candidate discs: the family 'vwide' described in the article.
# Usage:  PROF=P python3 explore_discs.py <m> <d> [eta]      -> expl_m<m>_d<d>_<PROF>_eta<eta>.json (input of certify_hybrid.py)
import numpy as np, sys, os, json, time, math
from scipy.optimize import linprog, minimize
from scipy import sparse
from lpcommon import f, F, basis, tgrid, bourgain_nodes, J_float

PROF = os.environ.get('PROF', 'P')
if PROF == 'P':
    from profile_published import nodes_published; nodes = nodes_published()
elif PROF == 'B': nodes = bourgain_nodes()
else: raise SystemExit('PROF must be P or B')

def Wmat(discs, bb, tt):
    # sparse matrix of W_k(b,t) = log^+(R_k / sqrt((c_k - 1/2 - b)^2 + (t + v_k)^2))
    rows = []; cols = []; vals = []
    for k, (c, R, v) in enumerate(discs):
        dist = np.sqrt((c-0.5-bb)**2+(tt+v)**2)
        w = np.log(R/np.maximum(dist, 1e-300)); i = np.nonzero(w > 0)[0]
        rows.append(i); cols.append(np.full(len(i), k)); vals.append(w[i])
    r = np.concatenate(rows) if rows else np.zeros(0, int)
    return sparse.csr_matrix((np.concatenate(vals) if vals else [], (r, np.concatenate(cols) if cols else [])), shape=(len(bb), len(discs)))
def Gmat(d, B, bb, tt): return np.array([F(d+bb, tt, k, j)+F(d-bb, tt, k, j) for (k, j) in B]).T

def solve(d, m, discs, eta=0.0, maxit=30, nb=26):
    B = basis(m); nB = len(B)
    sc = np.array([(d-0.5)**j for (_, j) in B])                 # scaling of the coefficients, for conditioning
    J = np.array([J_float(nodes, c, R) for c, R, v in discs])
    obj = np.concatenate([[sc[0]/(2*np.pi)], np.zeros(nB-1), J/np.pi])
    bb, tt = [a.ravel() for a in np.meshgrid(np.linspace(0, 0.5, nb), tgrid(300., 500, 300), indexing='ij')]
    def block(bb, tt): return sparse.hstack([sparse.csr_matrix(Gmat(d, B, bb, tt)*sc), Wmat(discs, bb, tt)]).tocsr(), f(bb, tt, d)+eta/(1+tt**2)
    A, Fv = block(bb, tt)
    arow = np.zeros(nB+len(discs)); arow[0] = 2*d*sc[0]; arow[1] = -2*sc[1]
    bf = np.linspace(0, 0.5, 101); tp = np.unique(np.concatenate([np.geomspace(1e-7, 3000., 6000), np.linspace(1e-4, 3., 30000)])); tf = np.concatenate([-tp[::-1], tp])
    def violation(x, used, du, bb, tt):   # f + margin - U - sum kappa W at the points (bb, tt); positive = violated
        v = f(bb, tt, d)+eta/(1+tt**2)-Gmat(d, B, bb, tt)@(x[:nB]*sc)
        if len(used): v = v-Wmat(du, bb, tt)@x[nB+used]
        return v
    for it in range(maxit):
        for method in ('highs', 'highs-ds', 'highs-ipm'):   # the dual simplex and the interior point method are tried if HiGHS' default fails
            r = linprog(obj, A_ub=-sparse.vstack([A, sparse.csr_matrix(arow)]), b_ub=-np.concatenate([Fv, [eta]]),
                        bounds=[(None, None)]*nB+[(0, None)]*len(discs), method=method)
            if r.status == 0: break
        assert r.status == 0, 'LP solver: '+r.message
        x = r.x; used = np.nonzero(x[nB:] > 1e-12)[0]; du = [discs[k] for k in used]
        nbl = []; ntl = []; worst = -1; cand = []
        for b in bf:   # violations on a finer grid -> new cutting planes (local maxima of the violation along t)
            v = violation(x, used, du, np.full_like(tf, b), tf)
            worst = max(worst, v.max()); idx = np.nonzero((v > 0) & (v >= np.roll(v, 1)) & (v >= np.roll(v, -1)))[0]
            nbl += [b]*len(idx); ntl += list(tf[idx])
            top = np.argsort(v)[-3:]; cand += [(v[i], b, tf[i]) for i in top]
        # the grid can miss narrow dips of U + sum kappa W - f (near the edges of the discs): refine the largest grid values
        # of the violation, including negative ones, by a local maximisation in (b, t), and add the maxima found as cutting planes
        cand.sort(reverse=True)
        for v0, b0, t0 in cand[:40]:
            if t0 == 0: continue
            g = lambda p: -violation(x, used, du, np.array([min(max(p[0], 0.0), 0.5)]), np.array([p[1] if p[1]*t0 > 0 else t0]))[0]
            res = minimize(g, [b0, t0], method='Nelder-Mead', options={'xatol': 1e-7, 'fatol': 1e-12, 'maxiter': 400})
            bb_, tt_ = min(max(res.x[0], 0.0), 0.5), (res.x[1] if res.x[1]*t0 > 0 else t0)
            vv = -res.fun; worst = max(worst, vv)
            if vv > 0: nbl.append(bb_); ntl.append(tt_)
        print('  it %d  objective %.6f  worst violation %.2e  new cutting planes %d  rows %d' % (it, r.fun, worst, len(nbl), A.shape[0]), flush=True)
        if not nbl: break
        # new cutting planes, without near-duplicates (which make the linear programme ill-conditioned)
        pts = []
        for b_, t_ in zip(nbl, ntl):
            if all(abs(b_-b2) > 1e-6 or abs(t_-t2) > 1e-6*max(1.0, abs(t_)) for b2, t2 in pts): pts.append((b_, t_))
        A2, F2 = block(np.array([p[0] for p in pts]), np.array([p[1] for p in pts])); A = sparse.vstack([A, A2]).tocsr(); Fv = np.concatenate([Fv, F2])
    xs = x.copy(); xs[:nB] *= sc
    return r.fun, xs, B, J, worst, it

def family_vwide():
    # centres c, radii R = c - 1 + x with R <= c - 1/2, vertical offsets v
    C = [1.03, 1.06, 1.1, math.log(3), 1.15, 1.2, 1.25, 1.3, 1.4, 1.5, math.log(5), 2.0, math.e, 3.0]
    out = []
    for c in C:

                if abs(v) <= R+2.5: out.append((c, R, float(v)))
    return out

\appsub{\texttt{opt\_line.py: the second-order cone programme of one explicit line}}

# Search program (not a certificate): optimise one explicit line |N(T)-main(T)| <= A1 log T + A3 for a target height L* = log T*.
# Kernel U = sum c_iota G_iota (basis R1..R_mR, I2..I_mI), d fixed. Convex programme (second-order cone, Clarabel through cvxpy):
#   minimise  (c_R1/2pi) L* + C_zeta(c) + z
#   s.t.      f(b,t) + eta/(1+t^2) <= U(b,t)      on a (b,t) grid, refined by cutting planes
#             2d c_R1 - 2 c_R2 >= eta              (limit of t^2 U at |t| -> oo)
#             z >= F_u(T;c), z >= F_l(T;c)         on a T grid in [1,1e6], and z >= the limit at T = oo
# C_zeta(c) = sum_n Lambda(n) n^{-sigma1} || (a(log n), b(log n)) ||_2  (n <= n0) + quadrature of the tail; with PPMAX > 0 the
# primes p <= PPMAX enter through the maximum of f_p over a grid of 96 phases (per-prime phase maximum).
# Usage:  [PPMAX=300] python3 opt_line.py <d> <mR> <mI> <L*> <out.json>
# Output: JSON with the coefficients as exact binary numbers, the input of certify_line_pp.py.
import sys, json, math, time, os, numpy as np, cvxpy as cp, mpmath as mp
PPMAX = int(os.environ.get('PPMAX', '0'))   # per-prime phase maximum in the objective for the primes p <= PPMAX (0: none)
sys.path.append(os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'hybrid_asymptotic'))   # lpcommon.py lives there (or next to this file in the flat archive)
from lpcommon import f, F, tgrid

def basis(mR, mI): return [('R', j) for j in range(1, mR+1)] + [('I', j) for j in range(2, mI+1)]

def kernel_rows(d, B, bb, tt):
    G = np.array([F(d+bb, tt, k, j) + F(d-bb, tt, k, j) for (k, j) in B]).T
    return G, f(bb, tt, d)

def primes(N):
    s = np.ones(N+1, bool); s[:2] = False
    for i in range(2, int(N**0.5)+1):
        if s[i]: s[i*i::i] = False
    return np.nonzero(s)[0]

def czeta_data(d, B, n0):
    # rows (one per prime power n <= n0, then one per quadrature node of the tail) such that
    # C_zeta ~ sum_rows w * || (rows_a @ c, rows_b @ c + beta0) ||_2;  prime_of[row] = p for the row of n = p^k, 0 for the tail
    s1 = 0.5+d; rows_a = []; rows_b = []; beta0 = []; w = []; prime_of = []
    def add(L, wt, p):
        rows_a.append([-(L**(j-1)/math.factorial(j-1))/math.pi if kk == 'R' else 0 for (kk, j) in B])
        rows_b.append([-(L**(j-1)/math.factorial(j-1))/math.pi if kk == 'I' else 0 for (kk, j) in B])
        beta0.append((math.exp(-d*L)-2)/(L*math.pi)); w.append(wt); prime_of.append(p)
    for p in primes(n0):
        lp = math.log(p); n = p; k = 1
        while n <= n0:
            add(k*lp, lp*math.exp(-s1*k*lp), int(p)); n *= p; k += 1
    # tail n > n0: psi(x) ~ x, sum Lambda(n) g(n) ~ int g(x) dx = int g e^L dL ; Gauss-Legendre in L on [log n0, 700]
    xg, wg = np.polynomial.legendre.leggauss(400); a, b = math.log(n0), 700.0
    for x, ww in zip(xg, wg):
        L = (b-a)/2*x+(a+b)/2; add(L, (b-a)/2*ww*math.exp((1-s1)*L), 0)
    return np.array(rows_a), np.array(rows_b), np.array(beta0), np.array(w), np.array(prime_of)


def czeta_pp_data(d, B, PP=300, n0=20000):
    """for primes p <= PP: list of (kvec, wvec, RAk, RBk, b0k) to build max_x f_p(x) on a grid; other n via hypot rows."""
    s1 = 0.5+d; groups = []
    for p in primes(PP):
        lp = math.log(p); n = p; k = 1; ks = []; ra = []; rb = []; bz = []
        while n <= n0:
            L = k*lp; w = lp*math.exp(-s1*L)
            ra.append([-w*(L**(j-1)/math.factorial(j-1))/math.pi if kk == 'R' else 0 for (kk, j) in B])
            rb.append([-w*(L**(j-1)/math.factorial(j-1))/math.pi if kk == 'I' else 0 for (kk, j) in B])
            bz.append(w*(math.exp(-d*L)-2)/(L*math.pi)); ks.append(k); n *= p; k += 1
        groups.append((p, np.array(ks), np.array(ra), np.array(rb), np.array(bz)))
    return groups

def elem_data(d, B, Tgrid):
    mp.mp.dps = 25
    s1r = mp.mpf(1)/2+d; s2r = mp.mpf(1)/2+2*d
    base = []; Phi = []
    for T in Tgrid:
        T = mp.mpf(T); s1 = s1r+1j*T; s2 = s2r+1j*T
        Ael = lambda s: mp.im(mp.log(s)+mp.log(s-1))-T/2*mp.log(mp.pi)+mp.im(mp.loggamma(s/2))
        base.append(float((2*Ael(s1)-Ael(s2))/mp.pi-T/(2*mp.pi)*mp.log(T/(2*mp.pi*mp.e))))
        row = []
        for (k, j) in B:
            if j == 1: D = 1/s1+1/(s1-1)-mp.log(mp.pi)/2+mp.psi(0, s1/2)/2
            else: D = s1**(-j)+(s1-1)**(-j)+(-1)**(j-1)/mp.factorial(j-1)/2**j*mp.psi(j-1, s1/2)
            row.append(float(mp.re(D)) if k == 'R' else float(-mp.im(D)))
        Phi.append(row)
    return np.array(base), np.array(Phi)

def optimize(d, mR, mI, Lstar, eta=2e-4, n0=20000, maxit=25, verbose=True):
    B = basis(mR, mI); nB = len(B); i1 = B.index(('R', 1)); i2 = B.index(('R', 2))
    isR = np.array([k == 'R' for k, _ in B])
    bb, tt = [a.ravel() for a in np.meshgrid(np.linspace(0, 0.5, 26), tgrid(300.), indexing='ij')]
    G, Fv = kernel_rows(d, B, bb, tt); Fv = Fv+eta/(1+tt**2)
    RA, RB, b0, w, prime_of = czeta_data(d, B, n0)
    if PPMAX:
        GR = czeta_pp_data(d, B, PPMAX, n0)
        maskPP = np.array([not (p and p <= PPMAX) for p in prime_of])     # rows of the prime powers p^k with p <= PPMAX are replaced by the phase maximum
        assert (~maskPP).sum() == sum(len(g[1]) for g in GR)
    Tg = np.unique(np.concatenate([np.geomspace(1, 1e6, 260), [1.0]]))
    base, Phi = elem_data(d, B, Tg); logT = np.log(Tg)
    sc = np.array([(d-0.5)**j for (_, j) in B])        # scaling for conditioning
    bfine = np.linspace(0, 0.5, 201); tp = np.geomspace(1e-8, 3000., 12000); tfine = np.concatenate([-tp[::-1], tp])
    for it in range(maxit):
        y = cp.Variable(nB); z = cp.Variable(); c = cp.multiply(sc, y)
        cons = [G@c >= Fv, 2*d*c[i1]-2*c[i2] >= eta]
        sign = np.where(isR, 1.0, -1.0)
        Fu = base+(Phi@c)/math.pi-c[i1]/(2*math.pi)*logT
        Fl = -base+(Phi@cp.multiply(sign, c))/math.pi-c[i1]/(2*math.pi)*logT
        cons += [z >= Fu, z >= Fl, z >= 7/8-c[i1]/(2*math.pi)*math.log(2*math.pi)]
        if PPMAX:
            xg = np.linspace(0, 2*np.pi, 96, endpoint=False); tp_ = cp.Variable(len(GR))
            for gi, (p, ks, ra, rb, bz) in enumerate(GR):
                Cm = np.cos(np.outer(xg, ks)); Sm = np.sin(np.outer(xg, ks))
                cons.append(tp_[gi] >= Cm@(ra@c)+Sm@(rb@c+bz))
            Cz = cp.sum(tp_)+cp.sum(cp.multiply(w[maskPP], cp.norm(cp.vstack([RA[maskPP]@c, RB[maskPP]@c+b0[maskPP]]), 2, axis=0)))
        else:
            Cz = cp.sum(cp.multiply(w, cp.norm(cp.vstack([RA@c, RB@c+b0]), 2, axis=0)))
        obj = c[i1]/(2*math.pi)*Lstar+Cz+z
        prob = cp.Problem(cp.Minimize(obj), cons); prob.solve(solver=cp.CLARABEL)
        assert prob.status in (cp.OPTIMAL, cp.OPTIMAL_INACCURATE), 'solver status: '+str(prob.status)
        cv = sc*y.value
        nb = []; nt = []; worst = -1
        for b in bfine:
            Gr, Fr = kernel_rows(d, B, np.full_like(tfine, b), tfine); v = Fr+eta/(1+tfine**2)-Gr@cv; worst = max(worst, v.max())
            idx = np.where((v > 0) & (v >= np.roll(v, 1)) & (v >= np.roll(v, -1)))[0]; nb += [b]*len(idx); nt += list(tfine[idx])
        if verbose: print('  it %d obj=%.5f C1=%.5f Cz~%.4f z=%.4f worst=%.2e' % (it, prob.value, cv[i1]/(2*math.pi), Cz.value, z.value, worst), flush=True)
        if not nb: break
        G2, F2 = kernel_rows(d, B, np.array(nb), np.array(nt)); G = np.vstack([G, G2]); Fv = np.concatenate([Fv, F2+eta/(1+np.array(nt)**2)])
    return dict(d=d, B=B, c=list(map(float, cv)), C1=float(cv[i1]/(2*math.pi)), Cz_est=float(Cz.value), z_est=float(z.value),

The running times printed at the end of the lines are informative only and depend on the machine; they are not part of the certified data. \section{Input data of the certificates}\label{app:data}
The following files hold the coefficients as decimal strings that round-trip to the binary floating-point numbers produced by the optimiser (the certifiers convert them to exact rationals), the disc data before rounding to rationals (the certificate rounds $c_k,R_k,v_k$ to denominators $\le10^4$ and then replaces $R_k$ by $\min(R_k,c_k-\frac12)$, as in \texttt{certify\_hybrid.py}), and the parameters of the search.
